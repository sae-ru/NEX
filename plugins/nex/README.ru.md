# NEX Developer Tools

[English](README.md) · [NEX](https://github.com/sae-ru/NEX) · [Публикация в каталоге](PUBLISHING.md)

Открытый навык и плагин для разработки приложений на **NEX — Neural Execution
Language, языке нейронного исполнения**. Навык запрашивает возможности
установленного компилятора, нужные правила языка и контекст символов, затем
проверяет завершённое изменение компилятором и подходящими тестами.

**Версия плагина: 0.1.1**, лицензия MIT. Версия плагина не является версией языка
или SDK. Пакет распространяется через GitHub; заявка в общий каталог OpenAI
пока не отправлена, одобрения каталога нет.

[Скачать ZIP для каталога](https://github.com/sae-ru/NEX/raw/refs/heads/main/plugins/releases/nex-developer-tools-0.1.1.zip)
и [проверить SHA256](../releases/nex-developer-tools-0.1.1.sha256).

## Установка навыка

Напишите в Codex:

```text
Используй $skill-installer и установи nex-programming из
https://github.com/sae-ru/NEX/tree/main/plugins/nex/skills/nex-programming
```

Пример задачи после установки:

```text
Используй $nex-programming. Создай небольшое приложение NEX с тестами.
Используй мой установленный SDK и напиши, как запустить результат.
```

Если навык не появился, перезапустите Codex. Для ручной установки скопируйте
каталог `skills/nex-programming` целиком в `.agents/skills/` вашего проекта
или в `~/.agents/skills/` для всех своих проектов. Сохраните примеры, инструкции
и LICENSE. При установленном плагине отдельная копия навыка обычно не нужна.

## Установка плагина с GitHub

Добавьте каталог плагинов через актуальный Codex CLI:

```sh
codex plugin marketplace add sae-ru/NEX --ref main
```

В настольном приложении откройте Plugins, выберите источник **NEX Developer
Tools** и установите плагин **NEX Developer Tools**. Если ваш клиент поддерживает
установку через CLI, можно выполнить:

```sh
codex plugin add nex-developer-tools@nex-plugins
```

Доступные команды показывает `codex plugin --help`. Каталог GitHub отличается
от общего каталога OpenAI; правила администратора рабочего пространства
продолжают действовать. Для локальной копии репозитория можно использовать
`codex plugin marketplace add /absolute/path/to/NEX`.

## Что требуется

Установите SDK NEX отдельно по
[инструкции](https://github.com/sae-ru/NEX/blob/main/docs/getting-started.ru.md).
Плагин требует локального исполнения и доступа к проекту. Он не содержит
компилятор, MCP-сервер, учётные записи или собственный облачный сервис.
Обработка исходников и вывода команд зависит от используемого вами агента.
Запускаемое приложение может иметь собственные побочные действия.

Навык сохраняет выбранную версию языка и зависимости существующего проекта.
Поддержку платформ, веба, GPU/NPU и других возможностей определяет SDK.
Измеренная экономия токенов этим пакетом не заявляется. Изменения самого
компилятора на C++ выполняются по правилам репозитория NEX.

## Архив для каталога

Из корня репозитория, используя Python 3.9 или новее:

```sh
python3 tools/package_codex_plugin.py --output /absolute/path/to/artifacts
```

Команда создаёт `nex-developer-tools-0.1.1.zip`, состав файлов и SHA256.
Порядок подачи, проверки и оставшиеся действия владельца описаны в
[PUBLISHING.md](PUBLISHING.md). Подготовка плагина не пересобирает SDK.
