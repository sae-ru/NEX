# Explicit private024 project contracts

This integration is selected by compiler-owned C++ SourceLanguage arguments.
The ordinary compiler CLI still uses public023. Editing nex.json or a capture
language field cannot enable024 or migrate an existing graph. Versioned physical
loads check the explicit source version and its matching dependency lock. Project
planning and capture never open a graph Store or execute a source entry point.

ABI5 uses nex.project-static-task-linkage/3 and nex.project-task-linkage/8,9,10
for plain/profile/logical-debug component plans. execution_abi is5 and imported
task calls use task-code/5. All records require separate boolean task_file_reads,
task_file_writes and task_file_streams fields. The compiler derives them from
checked reachable instructions and retained File values, not from OS grants.
A File transit can require a stream image without read/write authority.
Static/shared source edges retain the checked component ownership and one final
application runtime. Source remains available to the checker.

Capture parsing checks strict versioned shapes and masks. Replanning recomputes
actual sources, contracts, imports, exports and requirements before replay. Old
ABI3/4 records, masks31/799 and public023 stay distinct; relabelling a capture
cannot change its ABI. New captures serialize024 matching locks and retain all
selected source namespace relationships. Replayed builds and packaged programs
can execute with original sources absent. Application and project package
metadata derive language from their checked Program/source selection.

CPU/task profiles retain the actual ABI5 provider catalogs and source ownership.
Logical debug source unions preserve component language/revision/physical image.
The LLDB reader checks the descriptor ABI for each known source language. A024
File or aggregate containing one can expose a diagnostic file identity for a
pure watch. Decoding that identity creates no OS handle, grant or IO lease.
Effectful filesystem watches remain rejected. Retained task languages keep
historical File opacity and opaque task/scope/channel/effectful-callable rules.
File remains excluded from application wire values and task C FFI transport.

The maintained project suite uses real separately built static/shared libraries
with exported Box<file> functions, debug/release/profile/logical-debug modes,
source-deleted capture/replay and executable native packages. Boundary cases
reject malformed/downgraded records, foreign mask bits and tampered requirements;
retained023 plans/captures keep their ABI4 shapes. Actual CPU/task measurements
and all-stop LLDB/DAP sessions check File identity watches, IO rejection and
source projection after source projects are hidden. Temporary test output roots
are canonicalized; the product symlink refusal remains enforced.

These are private integration contracts, not public024, a new installed SDK or
cross-platform acceptance. Further controlled in-flight IO, genuine023 histories,
explicit public migration and full/SAN/SDK/platform delivery are required. All
original language, server, accelerator, UI/mobile, Studio, converter and quality
measurement work remains in scope.
