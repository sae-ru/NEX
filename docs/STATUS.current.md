**SDK 1.0.0** creates projects in language **0.30**. Download the archive for
macOS ARM64, Windows x64, Linux x86-64 or Linux ARM64. The compiler reports
**toolchain 1.0.0 / language 0.28 / task ABIs 7/8**. Here 0.28 is the fallback
for projects without a language selection. Projects can select 0.28, 0.29 or
0.30 in `nex.json`. Changing the language of a stored graph requires an explicit
migration. [Download the SDK](https://github.com/sae-ru/NEX/releases/tag/v1.0.0) · [Installation guide](getting-started.en.md)

The 1.x compatibility contract covers documented 0.30 source behavior, public
standard-library declarations, specified CLI fields and project history. On each
supported host, SDK 1.0.0 was tested with projects from the published 0.281.0
beta. The comparison records the archive hashes and results for each host.
[Compatibility contract](compatibility.md#compatibility-target-for-10) · [Results by host](https://github.com/sae-ru/NEX/releases/download/v1.0.0/compatibility.json)

Language 0.30 supports typed cells, [structured reference tasks](reference-tasks.md),
[persistent UI](persistent-ui.md), native libraries and
[persistent C++ host sessions](native-task-sessions.md).
[Native debugging](reference-provider-debugging.md) and
[profiling](reference-task-profiling.md) cover source-backed provider images.
Standalone HTTP owner-thread tasks support [LLDB/DAP](server-debugging.md#owner-thread-http-tasks-in-030)
and pinned-workload profiling. The [compatibility guide](compatibility.md)
defines the source and project contracts for SDK 1.x.
[Workboard](../examples/workboard/README.md) joins a browser UI, HTTP/tasks, SQLite,
file export/restore and a summary Worker; it is a required SDK consumption phase.
Ordinary libraries include [hash containers](hash-containers.md),
[ordered maps](ordered-containers.md) and [queues/heaps](sequence-containers.md).
[Java int](java-integers.md)/[long](java-long.md) have explicit domains;
the [IEEE kernel](ieee-numeric.md) still has no source types.
