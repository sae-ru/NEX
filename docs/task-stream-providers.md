## Contracts

Records8/9/10 select language0.24 and execution ABI5 with the unchanged88-byte
layout/offset40. Plain/profile/debug records have strict shapes and descriptor
requirements. PIC application stage3 includes explicit read/write/stream flags;
a direct static root keeps its ABI5 requirements in build/runtime metadata. Old records
cannot acquire streams by relabelling or adding fields. The compiler verifies
real artifact/source/cohort/signature/physical-owner contracts before linking.

A typed File export uses the compiler-private source ABI, not C FFI or wire.
Task/scope/channel/callable and generic opaque external authority exports retain
their existing rejection. A source task File originates from captured grants,
logical actor creation and a reserved owning executor cleanup slot. Cross-image
calls do not create another executor or upgrade a readonly handle. Existing
source snapshots enforce ancestor ownership, atomic promotion and retirement.

A file-bearing task slot requires stream image support even with no read/write
operation. Open/read and open-write/append/write/flush retain separate flags;
seek/size/close/is_open and file transit cannot request a new root grant. Shared
images record per-component flags and one pinned common runtime. Source remains
available to the checker while actual calls consume separate native artifacts.
