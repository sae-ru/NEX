## Scope and provenance

The [machine-readable evidence](evidence/llm-qwen38-27b-0.280.1-2026-11-17.json)
pins the freeze, ledger, raw-call accounting, individual outcomes, compiler and
execution amendments. The model is Qwen3.8 27B Q8_0 with GGUF revision
`f0fc43cfd802bd87bc7b95f2120553a6407848e3229126b623cc397427857e8a`.
The compiler is the0.280.1 source build from SDK source commit `bfb34928`,
using explicit language0.30. It is distinct from the relocated SDK binary.

The [version2 protocol](../experiments/quality/llm-campaign-v2/protocol.md) keeps
the ten original behavioral contracts and two deterministic repeats per language.
It adds the bounded common coding contract and compiler-derived reference
actions. The sampling, author/review budgets and full transcript accounting
remain frozen. This is one model and one task set; the repeats do not establish
independent stochastic success rates or large-project productivity.

The earlier [version1 result](llm-cost-qwen38-27b-2026-11-11.en.md) remains4/20
NEX,14/20 C++ and20/20 Python. Model weights match, but the selected inference
runtime changed from2.60.0 to2.73.0, as did NEX language and reference inputs.
Differences cannot be attributed solely to the shorter prompt or newer language.
The study measures development work, not generated-program speed. It is not an
exclusive-host latency benchmark.

## Retained failures and execution amendments

NEX has10 budget-exhausted and4 failed attempts. Both repeats of
`associated-value-adapter` timed out on their first180-second request. Those
requests are identical after removing the loaded-instance identifier. The
correlation does not establish the cause; these are not proven unrelated
transport faults. Neither attempt was retried or removed.

After each inspected terminal provider stop, a separate recorded execution
amendment collected only the never-started suffix with the unchanged frozen
engine and budgets. Collection used bounded chunks with model unload/reload.
The original stopped execution and both failures remain unchanged. This differs
from the original protocol's clean-prefix-only resume rule and limits claims of
strict execution-protocol conformance. Infrastructure pilots remain separate.

The other two NEX failures are Unicode solutions rejected by model-assisted
source review after passing the functional native/reference cases. The reviewer
assumed that the NEX `slice` builtin might use byte or UTF-16 indexing. The
[language specification](language.md) defines Unicode scalar string operations.
These review judgments need a domain-informed audit; they are preserved as
original rejections, not retrospectively promoted to accepted attempts. Automated
source review is not a formal proof or human review.

## Work implied by this result

The next development block should improve bounded discovery for task and bytes
operations, give source reviewers the selected compiler's normative semantics,
and diagnose repeated invalid tool actions. Any new collection needs its own
frozen protocol and accounting. The current observations do not justify a
general speedup, token saving, or a recommendation to migrate all projects.
