# Private023 writer-provider example

This request is for the internal `nex_task_write_provider_probe`, not ordinary
public022 CLI project selection. Build the compiler test target and run:

```sh
NEX_FILES_ROOT=/your/explicit/directory NEX_FILES_WRITE=1 \
  /path/to/build/nex_task_write_provider_probe writer.request.json /new/output
```

The probe builds an actual code-only static archive and application and executes
the independent reference path. Its JSON reports the native executable; running
that executable with the same explicit filesystem grant writes `output` and
returns42. Change request `mode` to `shared` for fixed shared-image staging.
The grants are operator configuration and do not belong in the source request.
Public023, source-deleted replay/package and platform delivery remain pending.
